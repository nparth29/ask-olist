### Question 3: How many customers placed more than one order?

Default thinking:
```sql
SELECT COUNT(*) AS repeat_customers FROM (SELECT c.customer_unique_id FROM customers c JOIN orders o ON c.customer_id = o.customer_id GROUP BY c.customer_unique_id HAVING COUNT(o.order_id) > 1)
```
Assumptions: Identified unique customers using customer_unique_id as customer_id is unique per order.; Included orders of all statuses because the question asks for orders placed.

`low`:
```sql
SELECT COUNT(*) AS repeat_customers FROM (SELECT c.customer_unique_id FROM orders o JOIN customers c ON o.customer_id = c.customer_id WHERE o.order_status = 'delivered' GROUP BY c.customer_unique_id HAVING COUNT(o.order_id) > 1)
```
Assumptions: Identified unique customers using customer_unique_id.; Filtered for delivered orders (order_status = 'delivered').
